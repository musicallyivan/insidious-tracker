# Insidious Tracker

Tracker fan de la saga **Insidious** con:

- **Cronología completa** (orden de historia y orden de estreno)
- Marca películas como vistas (se guarda en el navegador)
- **Cuenta atrás** fija en la esquina hacia *Insidious: Out of the Further* (21 de agosto de 2026)

## Cómo abrirlo

Abre `index.html` en el navegador, o desde la carpeta:

```bash
# PowerShell
start index.html
```

No necesita servidor ni dependencias.
